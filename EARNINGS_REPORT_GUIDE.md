## 📅 Time Period Filters

### 1. **Today**
- Shows earnings for current day
- Updates in real-time as bills are completed
- Perfect for daily tracking

### 2. **This Week**
- Shows earnings from Sunday to today
- Weekly performance overview
- Compare repairers' weekly performance

### 3. **This Month**
- Shows earnings for current month
- Monthly salary/commission calculation
- Month-to-date tracking

### 4. **Custom Range**
- Select any start and end date
- Perfect for specific period analysis
- Example: Last quarter, specific week, etc.

---

## 📊 What Information is Shown

### For Each Repairer:

1. **Total Earnings**
   - Amount repairer earned in selected period
   - Green color for easy visibility
   - Based on commission percentage

2. **Jobs Completed**
   - Number of repair jobs done
   - Blue color
   - Shows productivity

3. **Total Revenue**
   - Total bill amount from all jobs
   - Purple color
   - Shows contribution to store

4. **Average Commission/Job**
   - Only for commission-based repairers
   - Orange color
   - Shows average earning per job

5. **Detailed Bill List**
   - Click "View X Bill(s)" to expand
   - Shows each bill with:
     - Bill ID
     - Customer name
     - Date
     - Total amount
     - Repairer's earning

## 💰 Commission Calculation

### How It Works:

1. **Bill Created**: Customer pays ₹2,500
   - Parts Cost: ₹2,000
   - Net Bill (Service): ₹500
   - Total: ₹2,500

2. **Net Profit Calculated**: ₹500 (Total - Parts)

3. **Repairer Commission**: 
   - If 30% commission: ₹500 × 30% = ₹150
   - Repairer earns: ₹150

4. **Store Profit**: ₹500 - ₹150 = ₹350

### Shown in Earnings Report:
- Repairer sees: ₹150 earned
- Job count: 1
- Revenue contributed: ₹2,500
